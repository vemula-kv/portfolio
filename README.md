# Vinod Kumar Vemula — Portfolio

Static React 18 portfolio (React loaded from CDN), using `index.html`, `script.js` and `style.css`.

## Run

Open `index.html` in a browser, or run `python -m http.server 8000` here and open http://localhost:8000.

## Deploy

Upload these files to any static host (GitHub Pages, Netlify or Vercel). The existing `CNAME` was preserved, so verify it matches your intended domain before publishing.
